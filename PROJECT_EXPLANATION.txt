MEDIUM BLOG PROJECT EXPLANATION
================================

What I fixed
------------
1. Removed old Pages Router patterns like getServerSideProps from the app router pages.
2. Converted the home page to an async App Router page.
3. Converted the post route to a valid dynamic App Router page.
4. Converted the API logic to App Router route handlers.
5. Fixed the Sanity comment schema so saved comments match the code.
6. Fixed image paths and a few class name mistakes.
7. Simplified layout/fonts so the project can build without fetching Google Fonts.

How the project works
---------------------
1. app/page.tsx shows all blog posts from Sanity.
2. app/post/[slug]/page.tsx fetches one blog post using the slug from the URL.
3. app/post/PostPageContent.tsx shows the post and lets the user submit comments.
4. app/api/createComment/route.ts receives the comment form data.
5. app/api/createComment.ts sends that data to Sanity.
6. sanity/schemaTypes/postType.ts and sanity/schemaTypes/comment.js define the Sanity content models.
